= Borrar una fuente de gancho
:allow-uri-read: 
:imagesdir: ../media/


[.api-doc-operation .api-doc-operation-delete]#DELETE# [.api-doc-code-block]#`/accounts/{account_id}/core/v1/hookSources/{hookSource_id}`#

Elimina el recurso Hook Source API especificado.



[[parameters]]
== Parámetros

[cols="5*"]
|===
| Nombre | Tipo | En | Obligatorio | Descripción 


| account_id | cadena | ruta | Verdadero  a| 
ID del recurso de cuenta que lo contiene

* ejemplo: {{.Account}}




| hookSource_id | cadena | ruta | Verdadero  a| 
ID de la colección hookSource que se va a listar

|===


[[response]]
== Respuesta

[source]
----
Status: 204, Indicates if the hookSource resource was deleted.
----
